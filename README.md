# Rocket Boots

Rocket Boots adds a lightweight flight system to Minecraft Bedrock Edition using Script API.

Equip the Rocket Boots and take to the skies with smooth aerial movement, hovering, vertical control, and built-in fall protection.

Unlike many flight add-ons, Rocket Boots uses a script-driven system and does not modify the player entity, improving compatibility with other add-ons.

## Features

*   Custom Rocket Boots item
*   Smooth mid-air movement
*   Hovering flight
*   Ascend with Jump
*   Descend with Sneak
*   Sprint flight acceleration
*   Built-in fall damage protection
*   Flight particles and visual effects
*   Multiplayer compatible
*   Realm compatible

***

## Requirements

### Experimental Features

This add-on requires the following experimental feature to be enabled:

*   **Beta APIs**

The add-on will not function correctly if Beta APIs are disabled.

***

## How To Use

### Activate Flight

1.  Equip the Rocket Boots.
2.  Jump into the air.
3.  Use movement controls to fly.

### Flight Controls

| Control       |Action           |
| ------------- |---------------- |
| Jump          |Ascend           |
| Sneak         |Descend          |
| Move          |Fly horizontally |
| Sprint + Move |Faster flight    |
| No Input      |Hover in place   |

***

## Compatibility

Rocket Boots was designed to minimize conflicts with other add-ons by avoiding player entity replacements whenever possible.

However, compatibility with every add-on cannot be guaranteed.

## Installation

1.  Import the Behavior Pack.
2.  Import the Resource Pack.
3.  Enable both packs in your world.
4.  Enable **Beta APIs**.
5.  Join the world and equip Rocket Boots.
